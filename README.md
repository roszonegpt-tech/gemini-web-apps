# 🌐 Gemini Web Apps Tracker

A centralized index of all web apps built across my 4 Gemini accounts.

## Quick Access

| Account | Nickname | Link to Directory |
|---------|----------|-------------------|
| Account 1 | Gemini-1 | [/accounts/gemini-1](/accounts/gemini-1/README.md) |
| Account 2 | Gemini-2 | [/accounts/gemini-2](/accounts/gemini-2/README.md) |
| Account 3 | Gemini-3 | [/accounts/gemini-3](/accounts/gemini-3/README.md) |
| Account 4 | Gemini-4 | [/accounts/gemini-4](/accounts/gemini-4/README.md) |

## About

Each account folder contains a `README.md` listing all web apps with:
- App name & description
- Gemini share link
- Status (active / archived / in-progress)
- Tags (game, tool, animation, etc.)
